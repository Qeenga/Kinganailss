# Kinga Nails Art

Statikus, reszponzív bemutatkozó weboldal a Kinga Nails Art részére.

## Oldalak
- `index.html` – Főoldal
- `services.html` – Szolgáltatások és árak
- `gallery.html` – Munkáim / galéria
- `blog.html` – Blog
- `contact.html` – Kapcsolat

## Használat
Az oldal külön build folyamat nélkül fut. Nyisd meg az `index.html` fájlt, vagy töltsd fel a repository tartalmát GitHub Pages / Netlify / Vercel statikus tárhelyre.

## Még véglegesítendő
- pontos árlista
- nyitvatartás
- Instagram / TikTok / Facebook linkek
- saját fotók és videók
